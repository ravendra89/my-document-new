Vulnerabilities 1. Administrator Account's Password Does Not Expire
Findings:

# Default Policy: domain password policy is already enforcing password expiration.


Setting	                       Current Value	 
Maximum password age	         42 days
Enforce password history	     24 password
Minimum password age	         1 day
Password complexity          	Enabled
Minimum password length	         7
Reversible encryption	       Disabled




# However When we run:

Get-ADUser Administrator -Properties PasswordNeverExpires,PasswordLastSet |
Select Name, PasswordNeverExpires, PasswordLastSet

on the Domain Controller, it is not checking the DC server's local Administrator account.

It is querying Active Directory and returning the domain Administrator account (DOMAIN\Administrator).

Your output:

Name             PasswordNeverExpires PasswordLastSet
----             -------------------- ---------------
Administrator    True                 7/23/2026 6:41:08 PM

means:

Account checked: Domain Administrator account
PasswordNeverExpires = True → The domain Administrator password is configured to never expire
PasswordLastSet = 7/23/2026 → The password was last changed on that date

Therefore, the finding:

Administrator Account's Password Does Not Expire

is valid for the domain Administrator account.

Why your GPO did not prevent this

Your GPO says:

Maximum password age = 42 days

That applies to normal domain users unless an account-level exception exists.

The following account setting overrides the domain password policy:

Active Directory Users and Computers
 └── Administrator
      └── Account tab
          └── Password never expires

Since your query returned True, this option is enabled.

What you should decide next

For a privileged domain Administrator account, the common remediation is:

Open Active Directory Users and Computers

Find:

Users → Administrator
Open Properties
Go to Account

Uncheck:

Password never expires
Apply

Or using PowerShell:

Set-ADUser Administrator -PasswordNeverExpires $false

After this, the Administrator account will follow:

Maximum password age = 42 days

from your domain password policy.


Vulnerabilities 2. Windows User Accounts With Unchanged Passwords

Step 1: Identify which accounts are affected

Run this on the Domain Controller:

Get-ADUser -Filter * -Properties PasswordLastSet,PasswordNeverExpires |
Select Name, PasswordLastSet, PasswordNeverExpires |
Sort PasswordLastSet


Look for accounts where:

PasswordLastSet is very old
PasswordNeverExpires = True


Step 2: Find accounts older than your policy (42 days)

Run:

$Days = 42

Get-ADUser -Filter * -Properties PasswordLastSet |
Where-Object {
    $_.PasswordLastSet -lt (Get-Date).AddDays(-$Days)
} |
Select Name, PasswordLastSet

This gives you users whose passwords are older than your GPO setting.

Step 3: Remediate normal user accounts

For regular users:

Option A — Force password change at next login

Example:

Set-ADUser username -ChangePasswordAtLogon $true

The user will be prompted to change the password during the next login.

Option B — Reset the password (administrator action)

Example:

Set-ADAccountPassword username -Reset

You will be prompted for the new password.

Step 4: Check accounts with "Password never expires"

Run:

Get-ADUser -Filter * -Properties PasswordNeverExpires |
Where-Object {
    $_.PasswordNeverExpires -eq $true
} |
Select Name

Review the results.

For normal user accounts, disable it:

Set-ADUser username -PasswordNeverExpires $false

After this, the account will follow:

Maximum password age = 42 days

from your domain policy.

Step 5: Handle service accounts separately

Do not blindly change passwords for accounts such as:

svc_sql
svc_backup
svc_app
svc_monitor

because applications may stop working.

For service accounts, consider:

Group Managed Service Accounts (gMSA)
A privileged access management solution
Documented exception with approval
Step 6: Verify after remediation

Run again:

Get-ADUser -Filter * -Properties PasswordLastSet,PasswordNeverExpires |
Select Name,PasswordLastSet,PasswordNeverExpires

You should see:

User accounts → recent PasswordLastSet
Normal users → PasswordNeverExpires = False
Exceptions → documented
