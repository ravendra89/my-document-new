# Join the windows ec2 instance to ad ( directory service)

1. create Directory service

2. Create role for EC2 and assign the iam permission to the role

AmazonSSMDirectoryServiceAccess
AmazonSSMManagedInstanceCore

3. Run command (SSM)

Create Run command and search the following Command document:

AWS-JoinDirectoryServiceDomain

Provide the required details. these details are available in the Directory services.

Directory Id
(Required) The ID of the AWS Directory Service directory.

Directory Name(Required) The name of the directory; for example, test.example.com

Dns Ip Addresses

select the target server and run the command.

4. check the runbook output

5. Aslo we can verify whethere domain is joined or not by login the server directly or access through session manager.

For the session manager, run the following command then it will display the domain name:

wmic computersystem get domain


5. login the server using ad credential and Installing Active Directory administration tools on a EC2 Windows Server instance:

In the Server Manager Dashboard, choose Add roles and features.

In the Add Roles and Features Wizard choose Installation Type, select Role-based or feature-based installation, and choose Next.

Under Server Selection, make sure the local server is selected, and choose Features in the left navigation pane.

In the Role section, select-  ADDS, DNS Server Tools, Active Directory Lightweight Directory Services

In the Features tree, select Remote Server Administration Tools

Now Review the information and choose Install.

6. verify it: 
 When the feature installation is finished, the Active Directory Domain Services  are available from the Start menu in the Administrative Tools folder.
 
 Also, it will showing in the server manager tool section.

7. run below command to confirm if server is joined the directory service(AD)

domain.msc
